# 大疆运动相机同步连拍（安卓遥控器）

用一台安卓手机通过蓝牙**同时控制多台大疆运动相机**（Osmo Action 系列 / Osmo 360）：

- **多机批量控制**：一台手机同时连接多台相机，统一群发快门，支持单机微调
- **定时连拍**：设定间隔（最小 0.5 秒）与张数，支持倒计时开始和指定时刻（HH:mm）自动开始
- **手机同步拍摄**：每次触发时手机后置相机同步拍一张，照片存到 `DCIM/OsmoSync`
- **实时状态**：每台相机的电量、当前模式、拍摄状态、剩余存储（每秒 2 次推送）
- **前台保活**：连拍期间前台服务 + WakeLock，息屏也能继续拍摄

## 支持机型

| 机型 | 支持 |
| --- | --- |
| Osmo Action 6 / 5 Pro / 4 | ✅（官方协议明确支持） |
| Osmo 360 | ✅ |
| Osmo Action 3 | 理论可用（社区反馈可用，未实测） |
| Osmo Action 1 / 2 | ❌（无此蓝牙协议，仅 WiFi，未实现） |

## 使用步骤

1. **相机端**：开机、解锁屏幕；如 Mimo App 或其他遥控器正连着，请先断开（蓝牙通道一次只允许一个主设备）。
2. **手机端**：安装 APK → 打开 → 授予蓝牙 / 相机 / 通知权限。
3. **扫描**：在"相机管理"页打开扫描开关，列表中带 `DJI` 标记的就是可连接相机（识别标准来自官方协议的厂商广播字段）。
4. **连接**：点击"连接"。**首次配对**时 App 会显示一个 4 位校验码，同时**相机屏幕会弹出确认框**，在相机上确认即可；之后重连无需确认。
5. **切换模式**：建议点"切拍照"把相机切到拍照模式（拍录键在拍照模式下=拍照，在视频模式下=开始/停止录像）。
6. **定时连拍**：切到"定时连拍"页 → 设置间隔 / 张数 / 开始时间 → 点"开始定时连拍"。屏幕上可以看到手机同步画面，每次触发的结果会记录在"拍摄记录"里。

## 同步精度说明

触发时序：手机通过 BLE 向所有已连接相机**并发写入**快门指令（写特征 0xFFF5，毫秒级完成），随后触发手机相机。所有相机在同一毫秒收到指令，实际出片时刻由相机各自快门延迟决定（通常同一批相机差异在几十毫秒内）。对多机位拍摄而言完全够用。

## 项目结构（app/src/main/java/com/osmosync/app/）

```
protocol/    DJI R SDK 协议层：CRC16/32、帧封装解析、指令构造
ble/         BLE 层：扫描识别、单相机 GATT 连接与握手状态机、多机管理
shooter/     定时连拍调度器
phone/       手机相机（CameraX）
service/     连拍前台服务
ui/          Compose 界面
```

## 构建

需要 JDK 17 + Android SDK（compileSdk 34）。Android Studio 直接打开即可；命令行：

```bash
./gradlew :app:assembleDebug
# 产物: app/build/outputs/apk/debug/app-debug.apk
```

## 协议来源与致谢

蓝牙控制协议来自大疆官方开源项目 [Osmo-GPS-Controller-Demo](https://github.com/dji-sdk/Osmo-GPS-Controller-Demo)（DJI R SDK 协议，MIT），本项目的帧封装已用官方文档给出的已知好帧做过字节级验证。多机握手细节参考了社区项目 [rhoenschrat/DJI-Remote](https://github.com/rhoenschrat/DJI-Remote) 与 [datagutt/node-osmo](https://github.com/datagutt/node-osmo)。

关键协议要素：服务 `0xFFF0`，写特征 `0xFFF5`，通知特征 `0xFFF4`；广播识别=厂商字段第 0/1/4 字节为 `0xAA/0x08/0xFA`；连接握手（0x0019）→ 按键上报（0x0011）触发快门 → 模式切换（0x1D04）→ 状态订阅（0x1D05）。

## 已知限制

- 安卓手机同时可用的 BLE 连接数一般 4~9 台，建议 ≤6 台相机。
- 手机拍照需要 App 在前台（CameraX 绑定进程级生命周期）；相机不受影响，息屏照常连拍。
- 休眠中的相机无法接收指令（官方协议支持"广播唤醒"，尚未实现），连拍前请保持相机亮屏。
- 部分机型固件升级后协议字段可能调整，如遇异常可对照官方 Demo 更新 `protocol/` 层。
