# 大疆运动相机同步连拍（安卓遥控器）

用一台安卓手机通过蓝牙遥控**大疆 Osmo Action 系列 / Osmo 360** 和 **影石 Insta360** 运动相机：

- **多机批量控制**：一台手机同时连接多台相机，统一群发快门，支持单机微调
- **定时连拍**：设定间隔（最小 0.5 秒）与张数，支持倒计时开始和指定时刻（HH:mm）自动开始
- **多手机协同**（v1.2+）：多台手机各带相机、跨设备同步开拍——主从架构，主机开热点，从机连入后自动 NTP 式时钟校准（局域网 ±5~20ms），主机一键开始，进度实时聚合
- **手机同步拍摄**：每次触发时手机后置相机同步拍一张，照片存到 `DCIM/OsmoSync`
- **休眠/唤醒**（v1.2+）：一键让相机休眠（0x001A）；通过广播唤醒包（WKP+相机MAC）远程唤醒休眠的相机
- **GPS 注入**（v1.3+）：手机定位按 1Hz 推送给所有已连接相机（官方 0x0017 指令），相机照片写入 GPS 元数据；手机自拍照片同步写入 GPS EXIF
- **分享 / 互传**（v1.4+）：拍摄记录里每张手机照片可一键调起系统分享面板，在小米/OPPO/vivo 等机型上选择"互传"即可直传互传联盟设备（Osmo Action 5 Pro 固件 v01.03.0330 起支持互传联盟协议）；也支持批量分享
- **相机照片导入**（v1.6+）：USB 线把相机连到手机（或 SD 读卡器），一键扫描导入 DJI 照片到 `DCIM/OsmoSync/Camera`，支持按连拍会话时间段筛选、按文件名去重
- **相机记忆**（v1.7+）：连过的相机自动记住（MAC/名称/型号），重启 App 直接出现在"我的相机"列表，休眠的相机一键"唤醒并重连"，无需重新扫描配对
- **实时状态**：每台相机的电量、当前模式、拍摄状态、剩余存储（每秒 2 次推送）
- **拍摄清单导出**（v1.2+）：每次触发的精确时间戳 + 各机成功情况导出 JSON，多机位素材按时间对齐
- **前台保活**：连拍期间前台服务 + WakeLock，息屏也能继续拍摄

## 使用步骤

1. **相机端**：开机、解锁屏幕；如 Mimo App 或其他遥控器正连着，请先断开（蓝牙通道一次只允许一个主设备）。
2. **手机端**：安装 APK → 打开 → 授予蓝牙 / 相机 / 通知权限。
3. **扫描**：在"相机管理"页打开扫描开关，列表中带 `DJI` 标记的就是可连接相机（识别标准来自官方协议的厂商广播字段）。
4. **连接**：点击"连接"。**首次配对**时 App 会显示一个 4 位校验码，同时**相机屏幕会弹出确认框**，在相机上确认即可；之后重连无需确认。
5. **切换模式**：建议点"切拍照"把相机切到拍照模式（拍录键在拍照模式下=拍照，在视频模式下=开始/停止录像）。
6. **定时连拍**：切到"定时连拍"页 → 设置间隔 / 张数 / 开始时间 → 点"开始定时连拍"。屏幕上可以看到手机同步画面，每次触发的结果会记录在"拍摄记录"里。
7. **多手机协同**（可选）：每台手机先各自连好自己的相机。选一台做主机（"协同"页 → 主机，提前在系统设置开好热点），其余切到"从机"自动发现并接入；从机列表出现后，主机设好参数点"开始协同连拍"——所有手机按校准后的时钟同步开拍。从机也可手动填主机 IP 连接。
8. **GPS 注入**（可选）：在"相机管理"页打开"GPS 注入到相机照片"开关，手机定位会按 1Hz 推送给所有已连接相机（官方 GPS 遥控器同款指令），相机拍摄的照片随之记录 GPS；手机自己拍的照片也会写入 GPS EXIF。户外空旷处信号最佳。
9. **Insta360 遥控模式**（可选）：影石相机与大疆架构相反——相机是蓝牙主设备，会主动连接遥控器。打开"Insta360 遥控模式"开关后，手机以 "Insta360 GPS Remote" 名义对外广播（GATT 服务 0xCE80），在相机的 设置→蓝牙/遥控器连接 菜单里选择该设备即可接入；接入后可对相机快门（拍照模式下拍照/视频模式开始停止录像）、切模式、息屏、关机，支持多台相机同时接入。

## 关于照片回传

相机照片传到手机有三条路径：

1. **USB 导入（全机型，App 内置）**：USB 线把相机连到手机（或 SD 读卡器），"定时连拍"页的"从相机导入照片"会扫描 DJI 照片并导入相册，支持按本次连拍会话的时间段筛选、自动去重。
2. **互传联盟（OA5 Pro 固件 v01.03.0330+）**：2025 年 3 月起 OA5 Pro 原生支持互传联盟（MTA）协议，在相机菜单里直接把素材"互传"给手机，手机系统自动接收，无需任何 App。
3. **蓝牙直传（不可行）**：DJI R SDK 蓝牙协议没有文件传输指令，BLE 带宽也无法承载照片。

App 的"导出清单"功能可把每次触发的毫秒级时间戳导出为 JSON，多机位后期按时间码对齐素材。

## 同步精度说明

触发时序：手机通过 BLE 向所有已连接相机**并发写入**快门指令（写特征 0xFFF5，毫秒级完成），随后触发手机相机。所有相机在同一毫秒收到指令，实际出片时刻由相机各自快门延迟决定（通常同一批相机差异在几十毫秒内）。对多机位拍摄而言完全够用。

## 项目结构（app/src/main/java/com/osmosync/app/）

```
protocol/    DJI R SDK 协议层：CRC16/32、帧封装解析、指令构造
ble/         BLE 层：扫描识别、单相机 GATT 连接与握手状态机、多机管理
shooter/     定时连拍调度器
phone/       手机相机（CameraX）
service/     连拍前台服务
ui/          Compose 界面
```

## 构建

需要 JDK 17 + Android SDK（compileSdk 34）。Android Studio 直接打开即可；命令行：

```bash
./gradlew :app:assembleDebug
# 产物: app/build/outputs/apk/debug/app-debug.apk
```

## 协议来源与致谢

**大疆**：蓝牙控制协议来自官方开源项目 [Osmo-GPS-Controller-Demo](https://github.com/dji-sdk/Osmo-GPS-Controller-Demo)（DJI R SDK 协议，MIT），本项目的帧封装已用官方文档给出的已知好帧做过字节级验证。多机握手细节参考了社区项目 [rhoenschrat/DJI-Remote](https://github.com/rhoenschrat/DJI-Remote) 与 [datagutt/node-osmo](https://github.com/datagutt/node-osmo)。

**影石 Insta360**：GPS 遥控器协议来自社区逆向工程 [pchwalek/insta360_ble_esp32](https://github.com/pchwalek/insta360_ble_esp32)（X3/ONE RS 实测：服务 0xCE80、指令帧 FC EF FE 86 00 03 01 [键位][事件]）、[TheAngryRaven/insta360-ble-gps-spec](https://github.com/TheAngryRaven/insta360-ble-gps-spec)（X4 唤醒与 GPS 遥控协议）与 [Insta360 X3 BLE remote (Hackaday)](https://hackaday.io/project/188975-insta360-x3-ble-remote-control-with-esp32)。

关键协议要素：服务 `0xFFF0`，写特征 `0xFFF5`，通知特征 `0xFFF4`；广播识别=厂商字段第 0/1/4 字节为 `0xAA/0x08/0xFA`；连接握手（0x0019）→ 按键上报（0x0011）触发快门 → 模式切换（0x1D04）→ 状态订阅（0x1D05）。

## 已知限制

- 安卓手机同时可用的 BLE 连接数一般 4~9 台，建议 ≤6 台相机。
- 手机拍照需要 App 在前台（CameraX 绑定进程级生命周期）；相机不受影响，息屏照常连拍。
- 休眠中的相机无法接收指令（官方协议支持"广播唤醒"，尚未实现），连拍前请保持相机亮屏。
- 部分机型固件升级后协议字段可能调整，如遇异常可对照官方 Demo 更新 `protocol/` 层。
